the leap — the “ohhh”

An agent is just a thing with state & logic

components hold only JSON. behavior — models, tools, DB — registers as a named resource: ModelRef("model:main"). that one rule is why a snapshot is plain JSON any process can resume.
Entity→an agent · task · shared blackboard (just an id)
Component→all state: Messages · ModelRef · PendingToolCalls · errors · interrupts
System→callLLM · executeTools · supervisor · healer
add / remove a component→what triggers systems (this replaces edges & routers)
World→entities + systems + resources + scheduler + snapshot
the twist — vs games AND vs LangGraph

Kill the tick loop.
Kill the edges.

A (system, entity) pair fires only on a foreign write to a component it watches. Its own writes never re-trigger it. Control flow emerges; the run ends at quiescence.

because state is data, not code…

Six things you get for free

01
Emergent flow
No edges, no router. Systems fire on dirty data; the run ends at quiescence.
02
Errors as components
A throw appends a SystemError chip. Failure becomes queryable state.
03
Kill & resume
Every step boundary is JSON. Pause survives process death by construction.
04
Time travel
Rewind & fork ≈ 3 lines. A primitive, not a replay reconstruction.
05
Deterministic parallelism
Pairs commit at a barrier; reducers merge fan-in. No silent last-write-wins.
06
Flight recorder
Every step logs scheduled pairs, vetoes, writes & timings. “Why didn't it fire?”
feature, in motion

The ReAct loop has ZERO edges

reply w/ tool calls → dirties PendingToolCalls → wakes executeTools

tool result → Messages → foreign dirt → wakes callLLM

reply with no tool calls → world goes quiet → done.

feature, in motion

Errors are components.
Healing is a system.

A throwing system isn't a crashed run.

The engine discards its writes → appends a SystemError chip.

A healer watches ⟨SystemError⟩, retries, and it auto-clears.
